# UNO Multiplayer — GitHub Pages + Firebase

A mobile-first 2–4 player real-time UNO web game. The interface is inspired by the classic UNO table layout: players around the table, card backs for opponents, center draw/discard piles, turn ring, and your hand at the bottom.

## Free setup
1. Create a Firebase project and stay on the Spark (free) plan.
2. Add a Web app.
3. Enable Authentication → Anonymous.
4. Create Realtime Database.
5. Put the Firebase Web App config in `game.js`.
6. Upload these files to a GitHub repository.
7. Enable GitHub Pages from Settings → Pages → Deploy from branch → main / root.

Do not add billing or upgrade to Blaze for this small free project. Firebase free quotas still apply.
